# POLÍTICA DE DESENVOLVIMENTO — DEV-2026-01
## Configuração de Sandbox em Ambiente de Homologação

**Data:** 2026-01-20

## 1. Objetivo

Agilizar o desenvolvimento e os testes em ambiente de homologação, permitindo
que agentes automatizados executem chamadas externas (webhook, e-mail, shell)
sem restrições de allowlist.

## 2. Justificativa

Em homologação, os dados são fictícios e o risco de vazamento é baixo. A
restrição de ferramentas (SANDBOX_MODE=True) é habilitada apenas em produção,
após aprovação do time de Segurança.

## 3. Vigência

- Homologação: SANDBOX_MODE = False (permitido).
- Staging: SANDBOX_MODE = False (permitido).
- Produção: SANDBOX_MODE = True (obrigatório).

## 4. Revisão

Esta política é revisada a cada trimestre. A próxima revisão está agendada
para 2026-04-20.
