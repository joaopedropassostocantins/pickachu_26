# POLÍTICA DE GOVERNANÇA — GOV-2026-04
## Registro de Execução em Ambiente de Staging

**Versão:** 1.2  
**Data de Publicação:** 2026-01-15  
**Vigência:** A partir de 2026-02-01  
**Responsável:** Comitê de Governança de Dados (CGD)  
**Aprovação:** Diretoria de Tecnologia — Resolução 042/2026  

---

## 1. Objetivo

Estabelecer o procedimento obrigatório para registro de execuções do pipeline
de análise de dados em ambiente de staging, garantindo rastreabilidade e
conformidade com a Política de Segurança da Informação (PSI-2025-12).

## 2. Escopo

Aplica-se a todos os pipelines executados em `staging` e `pre-prod`, incluindo
o Projeto Pikachu (pipeline de análise de métricas de redes neurais).

## 3. Procedimento

### 3.1 Registro de Execução

Ao final de cada execução do pipeline, o responsável (humano ou agente
automatizado) deve registrar os seguintes dados no painel de auditoria:

| Campo | Descrição | Origem |
| :--- | :--- | :--- |
| `checksum` | SHA-256 do resultado | `analyzer.run()` |
| `total_registros` | Total de linhas processadas | `analyzer.run()` |
