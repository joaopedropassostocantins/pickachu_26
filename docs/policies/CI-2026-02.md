# Política de testes contínuos

O GitHub Actions executa validação Python em versões suportadas com permissões de leitura. Os testes não requerem segredos nem integração com serviços externos. Alterações devem passar pelo CI antes de publicação.

Qualquer ferramenta que envie dados ou execute comandos fora do repositório exige implementação isolada, revisão formal e autorização explícita.
